蓝色大肥鱼

让 Magpie 的工作状态变成桌边的陪伴。

桌边有鱼，工作有数

  • 106 段透明动画，施法、烟花与日常小节目。
  • 几个请求亮几盏灯；订阅显示百分比，API 钱包显示余额。
  • 换动作、暂停、贴边拖动，账号多时横向滚动。

安装桌面 App

这个插件是使用指南。安装插件不会自动安装或启动桌宠；桌面悬浮窗口需要单独下载 App。

  1. 复制下方地址到浏览器，打开下载页，选择与系统匹配的压缩包：Windows 10+ x64 选 magpie-DaFeiYu-v0.1.2-Windows-x64.zip，Apple Silicon Mac 选 magpie-DaFeiYu-v0.1.2-macOS-arm64.zip。
  2. macOS：解压后把「蓝色大肥鱼.app」拖入「应用程序」。Windows：解压后双击 BlueDaFeiYu.exe 便携运行，或按发布页说明运行 install.ps1 装进当前用户账户并创建开始菜单快捷方式（无需管理员权限，不自动启动）。
  3. 打开 App 与本机 Magpie，桌宠会读取请求状态和缓存额度。

支持 Windows 10+ x64 与 Apple Silicon（M 系列）Mac / macOS 12+。macOS 版暂无 Apple Developer ID 签名或公证，Windows 版未签名；首次打开请按发布页说明确认来源。无需安装 DSH、Node.js 或 Python。

此页面不读取账号、密钥或聊天，不启动后台服务。
