WINDOWS · MACOS × MAGPIE

DaFeiYu desktop pet

Magpie's live status, as a companion on your desktop.

This page is only a guide

The desktop pet is a separate app that you download yourself. Installing this plugin does not install, download or start the app.

What the app shows

  • One bulb per request in progress.
  • Quota percentages for subscriptions and balances for API wallets, each with its own switch.
  • 106 transparent animations; drag it to a screen edge.

Install the app

  1. Open the release page in your browser and download the ZIP for your system: Windows 10+ x64, or Apple Silicon Mac with macOS 12+.
  2. macOS: unzip and drag the app to Applications. Windows: unzip and run BlueDaFeiYu.exe, or install.ps1 for a per-user install.
  3. Start the app while Magpie runs on this computer.

The macOS build is ad-hoc signed only, not notarized; the Windows build is unsigned. Check the source before opening it the first time.

How it talks to Magpie

The app reads Magpie on this computer only (127.0.0.1): request status every 2 seconds, quota cards every 30 seconds. It sends the token magpie-dafeiyu, or MAGPIE_API_KEY when you set one. This page reads nothing.

Character and animations: PC2005-cloud/dsh-pet, non-commercial use only. Gateway: yetone/magpie.
