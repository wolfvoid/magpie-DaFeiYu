# 蓝色大肥鱼 v0.1.3 · 逐条额度开关与供应商标识

- 「口粮余量」中的每个额度窗口都有独立持久开关，可分别决定是否显示在桌宠上；设置会跨重启保留。
- 桌宠逐项显示额度窗口，不再只取整账号最低值；徽章数量较多时自动换行。
- 额度徽章增加 Cursor、Codex、DeepSeek、Volcengine 供应商 logo；小框只显示 logo 与百分比或金额，窗口详情可悬停查看。
- Magpie 暂时断开时保留最近一次有效额度；重置时间已过的旧值仍显示 `—%`，不会把缓存值伪装成新数据。
- 隐藏桌宠后，可通过 Dock、菜单栏图标菜单或托盘菜单重新显示；Windows 与 macOS 共用同一恢复逻辑。
- README 演示图更新为四个额度框、一个激活账号与五盏请求灯泡；演示账号和额度均为合成数据。
- 保持 Windows 10+ x64 与 Apple Silicon macOS 12+ 的共享代码与既有安装、签名说明。
- 修复 macOS 构建环境配置，补发此前未成功发布的 v0.1.3 安装包。

本页只描述本版改动。安装包由 main 分支的 macOS 与 Windows CI 分别构建；请下载与系统匹配的压缩包，并核对文件完整性。

## 下载对应版本

- Windows 10+ x64：`magpie-DaFeiYu-v0.1.3-Windows-x64.zip`（解压后运行 `BlueDaFeiYu.exe`，或使用 `install.ps1` 安装）。
- Apple Silicon Mac：`magpie-DaFeiYu-v0.1.3-macOS-arm64.zip`（解压后拖入「应用程序」）。

`SHA256SUMS.txt` 用于检查下载完整性；Source code ZIP 不是应用安装包。

## 安装与签名

Windows 版无需管理员权限，安装到 `%LocalAppData%\Programs\magpie-DaFeiYu`，不设开机启动；程序未签名，SmartScreen 提示时请先核对来源。macOS 版仅 ad-hoc 签名，没有 Developer ID 签名或公证；若被拦截，请核对来源后在「系统设置 → 隐私与安全性」选择「仍要打开」，不要关闭 Gatekeeper。

详细步骤见 [README](https://github.com/wolfvoid/magpie-DaFeiYu#安装)。
