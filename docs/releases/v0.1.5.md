# 蓝色大肥鱼 v0.1.5 · Magpie 插件市场准备

- 读取本机 Magpie 时带上 `Authorization: Bearer magpie-dafeiyu`，Magpie 的用量统计会把这些读取记为本应用；设置环境变量 `MAGPIE_API_KEY` 后改用你的网关 key。
- 新增 Claude、Gemini、Qwen、OpenAI、Grok、GLM 供应商图标，来自 MIT 许可的 [yetone/magpie](https://github.com/yetone/magpie)。
- 请求灯泡始终排成一行；超过 8 个请求时显示 8 盏灯加「+N」。
- Magpie 插件页改为中英双语，跟随 Magpie 的界面语言，并适配窄窗口；页面开头写明它只是使用指南，安装插件不会安装、下载或启动桌宠 App。
- 插件页以 npm 包 `magpie-dafeiyu` 发布，只包含页面、图标与许可说明，不含任何可执行文件。

## 下载对应版本

- Windows 10+ x64：`magpie-DaFeiYu-v0.1.5-Windows-x64.zip`（解压后运行 `BlueDaFeiYu.exe`，或使用 `install.ps1` 安装）。
- Apple Silicon Mac：`magpie-DaFeiYu-v0.1.5-macOS-arm64.zip`（解压后拖入「应用程序」）。

`SHA256SUMS.txt` 用于检查下载完整性；Source code ZIP 不是应用安装包。

## 安装与签名

Windows 版无需管理员权限，安装到 `%LocalAppData%\Programs\magpie-DaFeiYu`，不设开机启动；程序未签名，SmartScreen 提示时请先核对来源。macOS 版仅 ad-hoc 签名，没有 Developer ID 签名或公证；若被拦截，请核对来源后在「系统设置 → 隐私与安全性」选择「仍要打开」，不要关闭 Gatekeeper。

详细步骤见 [README](https://github.com/wolfvoid/magpie-DaFeiYu#安装)。
