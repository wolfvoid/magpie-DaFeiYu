# 蓝色大肥鱼 v0.1.2 · Windows × macOS × Magpie

- 小步跨平台移植：同一共享代码库同时服务 Windows 10+ x64 与 Apple Silicon Mac（macOS 12+）；主界面、106 段动画、请求灯泡、额度显示与 Magpie 本地读取在两个平台行为一致。
- 平台差异保持窄范围：安装方式、应用数据目录、托盘图标（Windows PNG / macOS emoji）与打包签名；不引入平台分支或分叉。
- Magpie 本地配置沿用官方同一路径 `~/.config/magpie/settings.json`（遵循 `XDG_CONFIG_HOME`），Windows 与 macOS 一致，应用只读取、不修改。
- 新增 Windows 本地安装：ZIP 内含 `BlueDaFeiYu.exe` 与 `install.ps1`，按用户安装到 `%LocalAppData%\Programs\magpie-DaFeiYu`，仅创建开始菜单快捷方式；无需管理员权限、不设开机启动，也可直接便携运行 exe。
- Windows「打开 Magpie」依次在 `%LOCALAPPDATA%\Programs\magpie`、`%LOCALAPPDATA%\magpie` 与 Program Files 中查找 `magpie.exe`。
- Windows 安装器使用 Unicode 快捷方式接口，中文开始菜单名称和安装路径不依赖系统语言。
- macOS 产物仍为 Apple Silicon arm64，保持 ad-hoc 签名，不含 Apple Developer ID 签名或公证。
- 单元测试覆盖 Windows / macOS / Linux 三个平台；发布产物分别在 macOS 与 Windows 打包。
- 冒烟测试产物写入 `DAFEIYU_QA_DIR` 或应用用户数据目录，不再写入应用安装目录。
- Magpie 页面插件更新为双平台指南，继续提示插件页面不会安装桌宠，并说明需选择与系统匹配的压缩包。
- 保留全部 106 段动画与请求灯泡、暂停、换动作、贴边拖动、多账号额度；素材非商用授权不变。

本页描述本版本包含的改动；发布验证以仓库 CI 与各平台提示为准，请按对应平台的说明核对来源后使用。

## 下载对应版本

- Windows 10+ x64：`magpie-DaFeiYu-v0.1.2-Windows-x64.zip`（解压后运行 `BlueDaFeiYu.exe`，或按下方说明用 `install.ps1` 安装）。
- Apple Silicon Mac：`magpie-DaFeiYu-v0.1.2-macOS-arm64.zip`（解压后拖入「应用程序」）。

压缩包名称中的系统后缀即目标平台，请勿混用。`SHA256SUMS.txt` 用于检查下载完整性；Source code ZIP 不是应用安装包。

## Windows 安装

解压后在解压目录中执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

`-ExecutionPolicy Bypass` 只作用于这一次进程，不会修改系统执行策略。安装按当前用户进行，位置为 `%LocalAppData%\Programs\magpie-DaFeiYu`，只创建开始菜单快捷方式；不需要管理员权限，也不会设置开机启动。不想安装时，进入解压后的 `蓝色大肥鱼-win32-x64` 文件夹，运行 `BlueDaFeiYu.exe` 即可。

更新前先从托盘菜单退出桌宠。卸载时运行安装目录中的 `install.ps1 -Uninstall`，用户设置会保留。

Windows 版未签名；若 SmartScreen 提示，请先核对下载来源再选择继续运行，不要关闭系统安全防护。

## macOS 安装

解压后把「蓝色大肥鱼.app」拖入「应用程序」，再从菜单栏打开。仅支持 Apple Silicon（M 系列）/ macOS 12+。更新前先退出旧版本。

App 只有 ad-hoc 签名，没有 Apple Developer ID 签名或公证。若系统阻止打开，请核对来源后在「系统设置 → 隐私与安全性」查看「仍要打开」。不要关闭 Gatekeeper。

## Magpie 页面插件

`magpie plugin add github:wolfvoid/magpie-DaFeiYu`

安装后在 Magpie 侧边栏打开「蓝色大肥鱼」，按指南选择与系统匹配的压缩包。安装页面不等于安装桌宠。
