# 蓝色大肥鱼 v0.1.1 · Mac × Magpie

- 项目统一命名为 `magpie-DaFeiYu`，版本回到更合适的 `0.1.x` 系列。
- 订阅账号显示百分比；Magpie 返回余额类型的 API 账号显示带币种金额。
- 新应用图标；保留全部 106 段动画与请求灯泡、暂停、换动作、贴边拖动。
- 精简 Electron 语言资源与开发文件，动画不压缩、不删减。
- 包含 Magpie 页面使用指南；桌面 App 仍需单独下载。

## 安装桌面 App

下载 `magpie-DaFeiYu-v0.1.1-macOS-arm64.zip`，解压后将「蓝色大肥鱼.app」拖入「应用程序」。更新前先退出旧版本。
支持 Apple Silicon（M 系列）Mac / macOS 12+，不支持 Intel Mac。
无需 Node.js、Python 或 DSH。请求与额度需要本机 Magpie。

App 只有 ad-hoc 签名，没有 Apple Developer ID 签名或公证。若系统阻止打开，请核对来源后在「系统设置 → 隐私与安全性」查看「仍要打开」。不要关闭 Gatekeeper。
`SHA256SUMS.txt` 用于检查下载完整性。Source code ZIP 不是应用安装包。

## Magpie 页面插件

`magpie plugin add github:wolfvoid/magpie-DaFeiYu`

安装后在 Magpie 侧边栏打开「蓝色大肥鱼」，按指南下载 App。安装页面不等于安装桌宠。
