# 蓝色大肥鱼 v0.1.4 · 菜单精简与额度总开关

- 右键菜单不再单独列出「放烟花」「凭空生花」「蓝鲸现世」，它们仍可在「点播全部动作」中找到。
- 「恢复全部额度显示」移入「额度与设置」：「口粮余量」右侧新增一键总开关，全部显示或全部隐藏，下方各条开关同步跟随。
- 隐藏桌宠后，单击 Dock 中的 App 图标即可恢复显示。
- 桌宠上余额制账号待刷新时只显示 `?`；面板中仍显示「待刷新」。
- 额度徽章从角色脚下开始向下排列，左右留白，最多 5 行，更多时在区域内滚动；窗口高度随行数变化，不再遮挡角色。
- 只要 Magpie 给出数值就照常显示，不再因数据超过 10 分钟而变成 `—%` 或 `?`；重置时间已过的额度仍显示 `—%`。面板中 API 余额也显示数据时间。
- 面板底部只保留本项目 GitHub 地址，可点击在浏览器中打开；素材来源与许可说明见仓库 README 和随 App 附带的许可证文件。

## 下载对应版本

- Windows 10+ x64：`magpie-DaFeiYu-v0.1.4-Windows-x64.zip`（解压后运行 `BlueDaFeiYu.exe`，或使用 `install.ps1` 安装）。
- Apple Silicon Mac：`magpie-DaFeiYu-v0.1.4-macOS-arm64.zip`（解压后拖入「应用程序」）。

`SHA256SUMS.txt` 用于检查下载完整性；Source code ZIP 不是应用安装包。

## 安装与签名

Windows 版无需管理员权限，安装到 `%LocalAppData%\Programs\magpie-DaFeiYu`，不设开机启动；程序未签名，SmartScreen 提示时请先核对来源。macOS 版仅 ad-hoc 签名，没有 Developer ID 签名或公证；若被拦截，请核对来源后在「系统设置 → 隐私与安全性」选择「仍要打开」，不要关闭 Gatekeeper。

详细步骤见 [README](https://github.com/wolfvoid/magpie-DaFeiYu#安装)。
